# Banco de Dados — Loja Online

Projeto de modelagem e implementação de um banco de dados relacional
para uma loja online.

## Objetivo

Modelar as principais operações de uma loja online, desde o cadastro
de clientes e produtos até pedidos, pagamentos e entregas.

## Modelo de Dados

O modelo é composto pelas entidades:

- Cliente
- Endereço
- Pedido
- Item do Pedido
- Produto
- Categoria
- Pagamento
- Entrega


## Tecnologias

- MySQL
- MySQL Workbench
- SQL
- Modelagem de Dados

## Execução

O script SQL disponível em `SQL/LOJA_ONLINE.sql` contém a implementação
do banco de dados.

Para executar:

1. Abra o arquivo no MySQL Workbench.
2. Execute o script.
3. O banco de dados será criado conforme definido no arquivo SQL.
